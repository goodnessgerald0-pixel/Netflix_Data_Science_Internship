# Netflix Data Science Internship

This repository contains the tasks I completed during my Data Science Internship using the Netflix dataset.

## Tasks Completed

### Task 1 – Data Cleaning & Preprocessing

Cleaned and prepared the Netflix dataset by handling missing values, duplicates, and data formats.

### Task 2 – Exploratory Data Analysis

Performed data analysis and created visualizations to understand Netflix content, countries, genres, ratings, and release trends.

### Task 3 – Recommendation System

Developed a basic content-based recommendation system using TF-IDF and content similarity.

### Task 4 – Trend Prediction

Used Linear Regression to analyze Netflix content trends and predict future releases.

### Task 5 – Classification Model

Built and compared Logistic Regression and Decision Tree models to classify Netflix content as Movies or TV Shows.

### Task 6 – Business Insights Dashboard

Created interactive visualizations using Plotly and developed business insights and recommendations from the Netflix dataset.

## Tools Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Plotly
* Jupyter Notebook

## Results

Logistic Regression achieved **99.83% accuracy**, while Decision Tree achieved **99.60% accuracy**.

## Conclusion

The internship provided practical experience in data cleaning, exploratory data analysis, machine learning, recommendation systems, trend prediction, data visualization, and business analysis.
